2. Menu → Cash control: add only genuinely known on-duty context/windows, start once, retain public reference. The cutoff/expected Cash and relevant active Device set are frozen server-side.

4. Count physical Cash blind; save one exact amount, including0.00 explicitly. Resolve readiness, then commit and lock the observation. Unsaved input is not an implicit commit.
5. Authorized reviewer opens frozen values, reviews actual−expected sign and saves nonzero-variance explanation. Finalizer confirms; expected/actual/variance/context become immutable. Next baseline is actual; no automatic Cash movement.
